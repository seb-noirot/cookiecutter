# Cookiecutter JetBrains Plugin Changelog

## [Unreleased]

### Added

- Initial implementation of Cookiecutter integration for JetBrains IDEs
- New Project Wizard integration for creating projects from Cookiecutter templates
- "Generate from Cookiecutter Template" action for generating structures in existing projects
- Support for multiple template sources:
  - Local directory templates
  - GitHub templates (using `gh:` prefix)
  - GitLab templates (using `gl:` prefix)
  - Git repository URLs
- Settings page for configuring Cookiecutter executable path
- Recent templates list for quick access
- Interactive template parameter input
- Background task execution with progress indicators
